# 声衡智鉴官网

深圳技术大学健康与环境工程学院国家级大学生创新创业训练计划项目展示页。网站介绍空气声与颈部体表振动的配对采集、声振回放、穿戴结构与阶段成果。

## 预览与部署

用浏览器打开 `index.html` 即可预览。样式、交互和图片随站点提供。

在 GitHub Pages 仓库的 **Settings → Pages** 中选择 **Deploy from a branch → main → /(root)**。发布文件使用相对路径，仓库根目录保留 `.nojekyll`。

更新文案和图片引用时编辑 `index.html`，更新视觉样式时编辑 `assets/site.css`，更新图集和波形交互时编辑 `assets/site.js`。现有页面的 Tailwind 规则预编译在 `assets/tailwind.css`，供浏览器直接使用。
